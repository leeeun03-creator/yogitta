# 요깃따 Todo 리스트

PRD 기능(F) → 유저 스토리(US) → 큰 Todo(`Tn`) → 세부 Todo(`Tn-n`) 순서로 내려간다.

- **큰 Todo**는 전체 과정을 미리 나눠 둔 것이다. 동사로 끝나는 제목, PRD 연결, 완료 기준, 일차, 예상 시간, 의존을 적는다
- **세부 Todo**는 큰 Todo를 **시작할 때** 적는다. 동사로 끝나는 한 줄 + 완료 조건 + 예상 시간(30분~2시간) + 의존
- 완료 = 완료 조건의 테스트(코드 테스트 + 실제 테스트, 엣지 케이스 포함)를 모두 통과한 것 (`yogitta-test` 1장). 통과한 커밋에서 체크한다
- Todo가 바뀌면 `todo:` 커밋으로 아래 "Todo 변경 내역" 표도 함께 고친다
- 큰 Todo 번호는 기획서 6장과 같다. 우선순위는 PRD 6장의 P0 / P1 / P2를 따른다
