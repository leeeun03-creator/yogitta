# 요깃따 Todo 리스트

PRD 기능(F) → 유저 스토리(US) → 큰 Todo(`Tn`) → 세부 Todo(`Tn-n`) 순서로 내려간다.

- 읽고 쓰는 규칙은 `yogitta-todo` 스킬을 따른다
- 이 파일에는 **큰 Todo**만 챕터별로 한 줄씩 둔다 (동사로 끝나는 제목, PRD 연결, 완료 기준, 우선순위, 의존, 진행 수)
- **세부 Todo**는 큰 Todo를 시작할 때 `docs/todo/Tn.md`에 쓰고, 체크박스도 거기에만 둔다
- 큰 Todo는 세부 Todo가 모두 끝나고 직접 확인을 받으면 체크한다
- Todo가 바뀌거나 버그·오류를 고치면 `docs/todo/log/Tn.md`(여러 큰 Todo에 걸치면 `log/전체.md`)에 한 줄 남긴다
