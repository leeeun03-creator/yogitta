# T7. 가구 종류를 고르면 그 모양으로 바꾸기

챕터 4. 가구 · P0 · 의존 T6, T4 · PRD F4, F5, F6 / US4 · 인수 조건 "가구 변신", "이름 중복"
완료 기준: 60×50×90cm 보관함을 서랍장으로 바꾸면 같은 크기 안에서 서랍장 모양이 되고 물건은 남는다. 같은 이름은 저장이 막히고 안내가 뜬다. 2D·3D에 이름 라벨

  - 완료: 속성 패널에 "종류" 4열 8개(양문 수납장·서랍장·선반·벽걸이·책상·테이블·침대·보관함)가 있고 지금 종류는 강조색이다. 누르면 그 종류로 바뀌어 이름·2D 평면도가 따라 바뀐다. 높이가 기본 높이와 다르면 [기본 높이 180cm로] 버튼이 보인다. 2D 평면도에서 보관함만 점선 테두리이고 다른 종류는 실선, 침대는 정면 반대쪽에 머리판 띠가 있다. 실제 테스트 — 보관함 → 서랍장("서랍장 1", 실선), [기본 높이]로 높이 바뀜, 되돌리기. 엣지 — 지금 종류를 다시 누름(그대로), 키보드만으로(Tab · Enter), 돌린 침대의 머리판 방향, 360px에서 8개가 화면 안·버튼 44px, 길어진 이름이 가구 안에 들어감 · 의존 T7-1

- [ ] T7-4 3D에 수납 가구 모양 세우기 (양문 수납장·서랍장·선반·벽걸이)
