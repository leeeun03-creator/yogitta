# T6. 가구를 놓고 옮기고 돌리기

## 세부 Todo

- [ ] T6-1 가구 더하기·옮기기·돌리기·지우기 store 액션 만들기
  - 완료: 가구를 더하는(`addBox`), 옮기는(`moveBox`), 90도 돌리는(`rotateBox`), 지우는(`removeBox`) 순수 함수와 store 액션이 있고, 한 동작이 되돌리기 한 번이다. 새 가구는 보관함(칸 1개, 설치 높이 0, 물건 없음, 높이 90cm)이고 이름은 "보관함 1"부터 비어 있는 가장 작은 번호다. 위치는 돌린 모양까지 바닥 안으로 맞추고, 돌려서 바닥보다 커지면 돌리지 않는다. 화면 상태에 고른 가구가 있고, 그 가구가 지워지거나 되돌려져 없어지면 비운다. 코드 테스트 — 더하기·옮기기·돌리기·지우기·자동 이름. 엣지 — 빈 번호 채우기("보관함 1"·"보관함 3"이면 "보관함 2"), 번호 아닌 비슷한 이름("보관함", "보관함 1a"), 바닥 밖 위치는 바닥 경계로, 바닥보다 큰 가구, 0 → 90 → 180 → 270 → 0도, 좁은 바닥에서 길쭉한 가구 돌리기 막힘, 없는 가구, 원본을 바꾸지 않음 · 의존 T13-1
  - 실제 테스트는 가구를 놓는 화면이 생기는 T6-2에서 함께 한다 (`yogitta-test` 2장 예외)
- [ ] T6-2 가구 도구로 끌어서 보관함 놓기 (시안 04)
  - 완료: 그리기 도구 막대에 "가구"가 생기고(구역 선과 지우개 사이), 가구 도구로 끌면 미리보기 사각형과 크기("60 × 50 cm")가 보이고, 떼면 그 크기의 보관함이 생겨 점선 테두리·가운데 이름·정면 삼각형으로 보인다. 누르기만 하면 그 자리에 60 × 50 cm 보관함. 실제 테스트 — 끌어 놓으면 "보관함 1", 하나 더 놓으면 "보관함 2", 되돌리기로 사라짐. 엣지 — 바닥 밖까지 끌기(바닥 경계까지), 바닥 밖 누르기(무시), 아주 작게 끌기(최소 10cm), Esc·두 번째 손가락으로 취소, 격자 스냅 끄기, 360px 터치로 끌기 · 의존 T6-1
- [ ] T6-3 선택 도구로 가구를 골라 옮기기
  - 완료: 선택 도구로 가구를 누르면 골라져 강조색 테두리·이름 알약(시안 04)이 보이고, 빈 곳을 누르거나 Esc면 풀린다. 가구를 끌면 옮겨지고(격자 스냅, 바닥 밖으로 안 나감) 한 번 끌기가 되돌리기 한 번이다. 빈 곳을 끌면 지금처럼 2D 평면도가 움직인다. 가구를 놓으면 그 가구가 골라지고 선택 도구로 바뀐다. 실제 테스트 — 누르기·끌어 옮기기·되돌리기. 엣지 — 바닥 경계 너머로 끌기, 조금만 움직이고 떼기(누르기로 봄), 겹친 가구는 나중에 놓은 것, 끄는 중 두 번째 손가락(취소), 키보드만으로(Tab으로 가구 · Enter로 고르기 · 방향키로 10cm), 360px 터치로 끌기 · 의존 T6-2
- [ ] T6-4 가구를 90도 돌리고 지우기 (속성 패널 첫 모양)
  - 완료: 가구를 고르면 오른쪽(휴대폰은 2D 평면도 아래)에 속성 패널이 열려 가구 이름·크기("60 × 50 × 90 cm")·[90° 회전]·[삭제]가 보인다. 돌리면 가운데를 축으로 시계 방향 90도 돌고 정면 삼각형이 따라 돈다. 회전 핸들(정면 반대쪽)·R 키로도 돌리고, Delete 키·지우개로도 지운다. 실제 테스트 — 돌리기·지우기·되돌리기. 엣지 — 바닥 경계에서 돌리면 바닥 안으로 밀림, 바닥보다 길어 못 돌리면 버튼이 막히고 안내, 네 번 돌리면 처음, 지우면 패널이 닫힘, 지운 것을 되돌리면 다시 보임, 키보드만으로, 360px에서 패널이 화면 안 (물건이 든 가구 지우기 확인은 T16) · 의존 T6-3
- [ ] T6-5 놓인 구획의 구역을 가구 구역으로 보이기
  - 완료: 가구 가운데 점이 든 구획의 구역이 그 가구의 구역이다. 저장하지 않고 그때그때 계산해서, 구역 선을 나중에 긋거나 구역 이름을 바꿔도 따라간다. 속성 패널에 "구역 안방"(없으면 "구역 없음")이 보인다. 코드 테스트 — 가구마다 구역 찾기. 엣지 — 구역 없는 구획, 가운데가 구역 선·벽 위, 다른 구역으로 옮기기, 구역 이름 바꾸기·지우기, 가구를 놓은 뒤 구역 선을 그어 구역 만들기, 가구 50개 · 의존 T6-4, T5
- [ ] T6-6 3D 미리보기·3D 공간에 가구를 보관함 상자로 세우기
  - 완료: 가구가 3D에서 같은 자리·크기·방향으로 보관함 색(`#CDB79C`) 상자로 서고(면 음영·모서리 선), 정면에 손잡이 홈이 있어 정면 방향이 보인다. 코드 테스트 — 가구 → 3D 위치·회전 (2D y = 3D z). 엣지 — 회전 0·90·180·270도에서 3D 정면이 2D 정면 삼각형 쪽, 바닥 가장자리 가구, 가구 50개에서 오류 없음, 3D 그림 이름에 가구 수 · 의존 T6-1, T4
