  - 완료: 벽의 점 목록을 선분마다 벽 박스(가운데 x·z, 길이, 회전, 높이 110cm, 두께 12cm)로 바꾸는 순수 함수가 있다. 닫힌 벽은 마지막 점 → 첫 점 선분도 만든다. 3D 색(`colors3d.ts`)과 벽 높이 상수를 둔다. 코드 테스트 — 가로·세로·대각선 선분의 가운데·길이·회전, 2D y = 3D z, 사각형 벽 → 박스 4개. 엣지 — 회전 0·90·180·270도(거꾸로 그린 선분), 점 1개뿐인 벽은 박스 없음, 길이 0 선분은 건너뜀, 원본을 바꾸지 않음 · 의존 T3-6

- [ ] T4-2 상단 바에서 2D 평면도 / 3D 미리보기 바꾸기 (시안 04, 컴포넌트 시안 06)
  - 완료: 상단 바 가운데에 [2D 평면도 | 3D 미리보기] 전환 버튼(공통 부품 `Segmented`)이 있고, 누르면 2D 평면도 자리에 3D 미리보기가 나온다. 3D 미리보기에는 바닥(`#DCBB91`, 50cm 격자선 `#CFA87A`)이 공간의 바닥 크기대로 보인다. 3D 코드는 처음 3D 미리보기를 열 때 불러온다(첫 화면이 무거워지지 않게). 실제 테스트 — 전환 버튼 역할·이름·눌림 상태, 3D 미리보기에서 2D 평면도가 사라지고 다시 돌아옴, 3D 미리보기 이름("3D 미리보기, 바닥 6.0 × 4.5 m"). 엣지 — 3D 미리보기에서는 그리기 도구가 막힘, 3D에서도 되돌리기·다시하기가 됨, 360px에서 상단 바가 넘치지 않음, 키보드로 전환, 3D를 못 그리는 브라우저(WebGL 없음)에서는 안내 문구 · 의존 T4-1
- [ ] T4-3 3D 미리보기에 벽 세우기
  - 완료: 2D 평면도에 그린 벽이 3D 미리보기에서 같은 자리에 벽 박스(`#F6EAD8`, 모서리 선 `#9B7A5A`, 면 음영 윗면 1 · 앞면 0.86 · 옆면 0.74)로 선다. 3D 미리보기 이름에 벽 수가 나온다. 실제 테스트 — 사각형 벽을 그리고 바꾸면 "벽 4개", 되돌리면 줄어듦, 스크린샷을 시안 04·01과 비교. 엣지 — 벽 없음, 닫힌 연속선, 바닥 가장자리 벽, 지우개로 가운데를 지운 벽 · 의존 T4-2
- [ ] T4-4 3D 미리보기 카메라 만들기 (회전·줌·이동)
  - 완료: 처음에는 바닥 전체가 보이게 대각선 위에서 내려다본다(바닥 크기에 맞춘 거리). 마우스 끌기 회전, 휠 줌, 오른쪽 끌기 이동, 터치 한 손가락 회전 · 두 손가락 줌·이동이 된다. 코드 테스트 — 바닥 크기 → 처음 카메라 자리·거리. 실제 테스트 — 끌기·휠 뒤에 카메라가 바뀜(화면 상태로 확인), 2D로 갔다 와도 3D 미리보기가 다시 뜸. 엣지 — 바닥 아래로 돌아가지 않음, 너무 가깝거나 멀리 줌되지 않음, 아주 작은(1 × 1 m)·아주 큰(30 × 30 m) 바닥도 처음에 다 보임, 360px 화면 · 의존 T4-3
