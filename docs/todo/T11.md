## 직접 확인

배포 주소: https://leeeun03-creator.github.io/yogitta/ (Actions가 끝난 뒤 Ctrl+Shift+R)

- [ ] 처음 열면(또는 시크릿 창) 샘플 공간 "내 방"이 바로 보인다: 침실·작업 공간 구역 색, 침대·화장대 서랍장·옷장·책장·책상·보관함, 화장대 서랍장 2번째 서랍에 여권
- [ ] 공간 바꾸기로 "형 방"을 열 수 있고, 형 책상에도 여권이 있다
- [ ] 물건을 넣거나 가구를 옮기고 새로고침해도 그대로다. 공간을 바꾸고 새로고침하면 그 공간이 열린다
- [ ] 편집 모드 상단 바에 "자동 저장됨"이 보인다 (휴대폰은 좁아서 뺀다) ← 엣지
- [ ] 새로고침하면 메인 화면에서 시작하고 되돌리기 기록은 비어 있다 ← 엣지
- [ ] 공간을 모두 지우면 첫 실행 화면이 나오고, [샘플 공간 둘러보기]로 샘플 공간을 다시 연다 ← 엣지
- [ ] (개발자 도구 Application → Local Storage) `yogitta:v1` 값을 `{깨짐`으로 바꾸고 새로고침하면 샘플 공간과 "저장된 데이터를 읽지 못해…" 안내가 뜨고, `yogitta:v1:broken`에 원래 값이 남는다 ← 엣지
- [ ] 안내는 [×]로 닫힌다. 휴대폰에서는 안내가 화면 아래 내용을 가리니 닫고 쓴다 ← 엣지
- (알고 있는 한계) "검색된다"는 T10(검색)에서 샘플 공간으로 확인한다. 기기 사이 동기화는 없고 백업 파일(T13)로 옮긴다. 저장 실패는 개발자 도구로만 재현할 수 있어 실제 테스트로 확인했다

## 메모

- 처음 열 때 샘플 공간을 바로 보여 준다(인수 조건 "첫 접속", US11 평가자). PRD 흐름도의 [샘플 공간 둘러보기]는 공간을 모두 지운 뒤의 첫 실행 화면에 둔다
- 샘플 구성은 내 방 + 형 방 2개로 한다 (검색 결과 카드 시안의 "다른 공간에도 있어요: 형 방 1곳"을 보이려고)
- 검색("검색된다")은 T10에서 샘플 공간으로 확인한다
- 기존 실제 테스트는 빈 저장 데이터로 시작해 첫 실행 화면부터 본다 (Playwright storageState). 샘플 공간 테스트만 저장 데이터 없이 시작한다
- 한 테스트에서 공간을 여러 번 만들면 앞 공간이 저장돼 있으므로, 실제 테스트 도우미 createSpace는 메인 화면이 뜨면 저장 데이터를 비우고 다시 연다 (T11-1 작업 중 테스트 11개가 여기서 걸렸다)
