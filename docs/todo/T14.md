# T14. 검색 결과에 같은 칸 물건 보여주기

## 세부 Todo

- [ ] T14-1 결과 카드에 같은 칸에 있는 물건 칩 보여주기
  - 완료: 찾은 물건과 같은 가구·같은 칸에 있는 다른 물건이 "같은 칸에 있는 물건" 칩으로 메모 아래·다른 공간 링크 위에 보인다(시안 07). 4개까지 보이고 더 있으면 "외 n개". 여러 곳이면 고른 결과의 것. 없으면 줄이 없다. 코드 테스트 — 같은 칸 물건 고르기(칸 없음끼리 포함, 찾은 물건 빼기), 4개 + 외 n개. 실제 테스트 — 샘플 "여권" → 칩 "비상금" · 의존 T10
- [ ] T14-2 같은 칸 물건 칩을 누르면 그 물건 찾기
  - 완료: 칩을 누르면 검색창이 그 물건 이름으로 바뀌고 그 물건 결과 카드가 뜬다. 실제 테스트 — "여권" → "비상금" 칩 → "요깃따!" 비상금 · 의존 T14-1
- [ ] T14-3 "외 n개"를 누르면 같은 칸 물건 모두 펼치기
  - 완료: "외 n개" 칩을 누르면 나머지 물건 칩이 모두 보인다. 코드 테스트 — 펼치면 다 보임 · 의존 T14-2
