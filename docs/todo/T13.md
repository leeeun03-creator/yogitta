# T13. 되돌리기 / 다시하기 만들기

챕터 2. 벽과 3D · P0 · 의존 T3 · PRD F13 / US6 · 인수 조건 "되돌리기"
완료 기준: 벽을 그리거나 지운 뒤 Ctrl+Z(또는 상단 바 되돌리기)를 누르면 이전 상태로 돌아가고, Ctrl+Shift+Z·Ctrl+Y(다시하기)로 다시 생긴다. 최대 50단계, 끝에서는 버튼이 막힌다. 가구(T6 이후)도 같은 방식으로 된다
