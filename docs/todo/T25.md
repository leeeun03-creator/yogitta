# T25. 메인 화면 틀을 만들고 편집 모드와 오가기

챕터 3. 공간 · P0 · 의존 T4 · PRD 8장 UX 플로우
완료 기준: 메인 화면(머리·검색창 자리·3D 공간)과 편집 모드를 [편집]·[‹ 완료]로 오가고, 공간이 없으면 첫 실행 화면이 나온다
변경 로그: [log/T25.md](log/T25.md)

## 세부 Todo

- [ ] T25-1 편집 모드와 메인 화면 오가기
  - 완료: 새 공간을 만들면 편집 모드가 열리고, 상단 바 [‹ 완료]를 누르면 메인 화면, 메인 화면 [편집]을 누르면 다시 편집 모드가 된다. 벽·구역 선·구역은 그대로다. 공간이 없으면 첫 실행 화면. 코드 테스트 — 오갈 때 바뀌는 store 상태. 실제 테스트 — 만들기 → 편집 모드 → 완료 → 메인 화면 → 편집 → 그린 벽이 그대로. 엣지 — 오가면 그리던 선·이름 입력칸은 버리고 도구는 선택·보기는 2D 평면도로, 되돌리기 기록은 남음, 메인 화면에서 Ctrl+Z는 아무 일 없음, 키보드만으로 오가기(초점이 새 화면으로), 빠르게 두 번 누름 · 의존 T4
- [ ] T25-2 메인 화면 머리와 3D 공간 보이기 (시안 01)
  - 완료: 메인 화면 머리에 로고, 지금 공간 이름 알약("공간 내 방"), [편집] 버튼이 있고, 아래 3D 공간에 바닥·구역 색·벽이 편집 모드와 같게 보이며 시점·줌 버튼이 된다. 3D 공간 이름에 바닥 크기·벽 수·구역 수가 나온다. 실제 테스트 — 벽을 그리고 완료하면 3D 공간 이름에 그 벽 수, 시점·줌 버튼. 엣지 — 벽 없는 공간, 3D를 못 그리는 브라우저 안내, 10자 넘는 공간 이름(넘치지 않음), 스크린샷을 시안 01과 비교 · 의존 T25-1
  - 공간 이름 알약을 눌러 공간 바꾸기는 T27에서 한다 (지금은 버튼이 아닌 표시)
- [ ] T25-3 검색창 자리를 만들고 휴대폰 메인 화면 맞추기 (시안 02)
  - 완료: 머리 아래 가운데에 알약형 검색창(보이지 않는 라벨 "물건 검색", placeholder "무엇을 찾고 있나요?", 돋보기 아이콘)이 있다. 360px에서는 머리(로고·공간 이름·편집 아이콘 버튼) → 검색창 → 3D 공간 순서다. 실제 테스트 — 검색창을 라벨로 찾고 글자를 쓸 수 있다. 엣지 — 360px 가로 스크롤 없음, 버튼·검색창 44px 이상, 아주 긴 검색어, 키보드로 검색창 → 편집 버튼, 스크린샷을 시안 02와 비교 · 의존 T25-2
  - 검색해서 결과를 보여주는 것은 T10에서 한다
