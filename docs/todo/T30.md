# T30. 칸 높이와 벽걸이 설치 높이 입력하기

- [x] T30-1 칸마다 높이를 넣어 3D 칸 모양 바꾸기
  - 완료: 속성 패널(양문 수납장·서랍장·선반·벽걸이)에 칸마다 높이 입력칸이 있고(처음엔 균등 분배 값), Enter·입력칸을 벗어나면 바꾼다(되돌리기 한 번). 3D 미리보기의 서랍 앞판·선반 판이 그 높이대로 바뀐다. 합이 전체 높이보다 작으면 남는 높이는 맨 아래 빈 자리가 되고, 넘으면 바꾸지 않고 까닭을 띄운다. 코드 테스트 — 칸 높이 바꾸기(균등 분배에서 시작, 합 검사, 최소 높이), 3D 칸 자리(합이 작으면 아래가 빔). 실제 테스트 — 서랍장 1번째 서랍을 20으로 바꾸면 저장되고 3D가 바뀜. 엣지 — 0·음수·숫자 아님·최소 미만·합이 넘음은 막고 까닭, Esc는 되돌림, 가구 높이·칸 수를 바꾸면 균등 분배로 돌아감 · 의존 T7
  - 결과: 코드 13개 추가 통과(칸 높이 정하기·합이 작으면 아래가 빔·칸 높이 바꾸기·안내 문구·cm 표시) · 실제 4개 통과(× 2화면) · 엣지: 합이 넘음, 숫자 아님, 10cm 미만, Esc, 되돌리기, 칸 수·높이 바꾸면 균등 분배 · 균등 분배 소수(22.5)는 그대로 보이고, 고치지 않은 칸은 입력칸을 벗어나도 반올림해 바꾸지 않는다 · 스크린샷: 속성 패널 칸 높이 입력칸, 3D 서랍 15·45·30 · 커밋 `T30-1: 칸마다 높이를 넣어 3D 칸 모양 바꾸기`
- [x] T30-2 칸 높이 합계와 칸 비율 미리보기 보여주기

- [ ] T30-3 벽걸이 설치 높이 넣기
  - 완료: 벽걸이를 고르면 속성 패널에 "설치 높이 (cm)" 입력칸(기본 150)이 있고, 바꾸면 3D에서 그 높이에 뜬다. 바닥에서 설치 높이 + 높이가 240cm를 넘지 않고, 높이가 겹치는 다른 가구와 겹치면 바꾸지 않고 까닭을 띄운다. 코드 테스트 — 설치 높이 바꾸기(범위, 겹침). 실제 테스트 — 120으로 바꾸면 저장되고 3D가 바뀜. 엣지 — 범위 밖·숫자 아님 막힘, 아래 가구와 높이가 겹치면 막힘 · 의존 T30-1
- [ ] T30-4 벽걸이를 가까운 벽에 붙이기
  - 완료: 벽걸이를 끌어 벽 가까이(30cm 안) 놓으면 뒷면이 벽 면에 붙고 정면이 벽 반대쪽을 보게 돈다(가로·세로 벽). 코드 테스트 — 가까운 벽 찾기, 붙인 자리와 방향(0·90·180·270도). 실제 테스트 — 벽 옆으로 끌면 붙음. 엣지 — 멀면 그대로, 비스듬한 벽·벽 끝 너머는 붙지 않음, 되돌리기 한 번 · 의존 T30-3
