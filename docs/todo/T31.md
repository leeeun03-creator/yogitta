# T31. 터치에서도 편하게 벽 그리기

챕터 2. 벽과 3D · P0 · 의존 T12 · PRD F2 / US3 · 비기능 "화면 폭 360px까지"
완료 기준: 직선·연속선을 누른 채 끌고 떼어 그릴 수 있고(두 번 누르기도 그대로), 터치로 끄는 동안 손가락 위 돋보기에 찍힐 자리가 보이며, 그리는 선 옆에 길이("1.2 m")가 보여 휴대폰에서도 짧은 선을 원하는 길이로 그릴 수 있다

## 세부 Todo

- [x] T31-1 직선·연속선을 끌어서 그리기
  - 완료: 직선 도구에서 누른 채 끌고 떼면 누른 점 → 뗀 점 벽이 생긴다. 연속선은 끌어서 첫 선분을 만들고, 이어서 끌거나 누를 때마다 점이 이어진다. 두 점 모두 스냅(끝점·격자)을 따른다. 두 번 누르기 방식은 그대로 된다. 코드 테스트 — 끌기 단계 계산(직선: 벽 완성, 연속선: 점 2개로 시작·이어 붙이기). 실제 테스트 — 데스크톱 마우스 끌기, 모바일 CDP 터치 끌기. 엣지 — 5px 안으로만 움직이면 누르기로 본다, 끌어서 같은 자리로 돌아오면(길이 0) 벽을 만들지 않는다, 끄는 중 Esc는 취소, 바닥 밖으로 끌면 바닥 경계, 두 손가락이 닿으면 그리기 대신 줌 · 의존 T12-3
  - 결과: 코드 135개 통과(끌기 단계 9개 새로) · 실제 187개 통과(29개 건너뜀) · 엣지: 5px 안 끌기는 누르기, 끌었다 제자리로 돌아오면 벽·점 없음, 끄는 중 Esc, 바닥 밖은 경계까지, 두 번째 손가락은 줌, 지우개도 끌었다 돌아오면 지우지 않음 · 한 번이라도 5px 넘게 끌면 누르기가 아니게 바꿈 · 누르기 취소를 고장 내면 지우개 테스트, 두 손가락 취소를 빼면 두 손가락 테스트 실패 ✓ · 끄는 동안 미리보기 선과 붙을 곳 점 스크린샷 확인 · 커밋 `T31-1: 직선·연속선을 끌어서 그리기`
- [ ] T31-2 그리는 동안 길이 표시하기
  - 완료: 직선·연속선 미리보기 선 가운데 옆에 지금 길이("1.2 m")가, 사각형 미리보기에는 "가로 × 세로"("3.0 × 2.5 m")가 보인다. 글자는 줌해도 화면 기준 같은 크기다. 코드 테스트 — 길이 글자 만들기(cm → "m" 소수 한 자리), 글자 자리(선 가운데에서 선과 직각으로 띄움). 엣지 — 길이 0이면 표시하지 않음, 세로선·거꾸로 끈 선도 글자가 선에 겹치지 않음, 바닥 가장자리 선은 글자가 화면 안에 · 의존 T31-1
- [ ] T31-3 터치로 끌 때 손가락 위 돋보기 보여주기
  - 완료: 손가락으로 그리기 도구를 끄는 동안 손가락 위쪽에 둥근 돋보기가 뜨고, 손가락 아래 영역을 확대해 벽·미리보기 선·붙을 곳 표시(고리·점)를 보여준다. 찍히는 좌표는 손가락 자리 그대로다. 손가락을 떼면 사라진다. 실제 테스트 — 모바일 CDP 터치로 끄는 동안 돋보기가 보이고 떼면 사라짐, 찍힌 좌표가 손가락 자리와 같음. 엣지 — 마우스로는 돋보기가 뜨지 않음, 화면 위쪽 가장자리에서는 돋보기가 화면 안으로 옮겨짐, 선택 도구로 끌 때는 뜨지 않음 · 의존 T31-2
