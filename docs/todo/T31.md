# T31. 터치에서도 편하게 벽 그리기

## 세부 Todo

- [x] T31-1 직선·연속선을 끌어서 그리기
  - 완료: 직선 도구에서 누른 채 끌고 떼면 누른 점 → 뗀 점 벽이 생긴다. 연속선은 끌어서 첫 선분을 만들고, 이어서 끌거나 누를 때마다 점이 이어진다. 두 점 모두 스냅(끝점·격자)을 따른다. 두 번 누르기 방식은 그대로 된다. 코드 테스트 — 끌기 단계 계산(직선: 벽 완성, 연속선: 점 2개로 시작·이어 붙이기). 실제 테스트 — 데스크톱 마우스 끌기, 모바일 CDP 터치 끌기. 엣지 — 5px 안으로만 움직이면 누르기로 본다, 끌어서 같은 자리로 돌아오면(길이 0) 벽을 만들지 않는다, 끄는 중 Esc는 취소, 바닥 밖으로 끌면 바닥 경계, 두 손가락이 닿으면 그리기 대신 줌 · 의존 T12-3
  - 결과: 코드 135개 통과(끌기 단계 9개 새로) · 실제 187개 통과(29개 건너뜀) · 엣지: 5px 안 끌기는 누르기, 끌었다 제자리로 돌아오면 벽·점 없음, 끄는 중 Esc, 바닥 밖은 경계까지, 두 번째 손가락은 줌, 지우개도 끌었다 돌아오면 지우지 않음 · 한 번이라도 5px 넘게 끌면 누르기가 아니게 바꿈 · 누르기 취소를 고장 내면 지우개 테스트, 두 손가락 취소를 빼면 두 손가락 테스트 실패 ✓ · 끄는 동안 미리보기 선과 붙을 곳 점 스크린샷 확인 · 커밋 `T31-1: 직선·연속선을 끌어서 그리기`
- [x] T31-2 그리는 동안 길이 표시하기
  - 완료: 직선·연속선 미리보기 선 가운데 옆에 지금 길이("1.2 m")가, 사각형 미리보기에는 "가로 × 세로"("3.0 × 2.5 m")가 보인다. 글자는 줌해도 화면 기준 같은 크기다. 코드 테스트 — 길이 글자 만들기(cm → m, 바닥 크기와 같은 규칙: 10cm 단위면 소수 한 자리, 아니면 두 자리), 글자 자리(선 가운데에서 선과 직각으로 띄움). 엣지 — 길이 0이면 표시하지 않음, 세로선·거꾸로 끈 선도 글자가 선에 겹치지 않음, 바닥 가장자리 선은 글자가 화면 안에 · 의존 T31-1
  - 결과: 코드 154개 통과(길이 글자·글자 자리·길이 표시 19개 새로) · 실제 204개 통과(32개 건너뜀) · 엣지: 길이 0, 세로선은 글자 폭만큼 띄워 겹치지 않음, 화면 위 가장자리 선은 아래쪽으로, 확대해도 같은 크기, 끌어도 글자가 선택되지 않음 · 테스트가 "세로선에서 글자가 벽에 겹침"과 "마우스로 끌면 치수·길이 글자가 선택됨"을 찾아 고침 · 글자 폭 띄우기를 빼면 실제 2개·코드 3개, 글자 선택 막기를 빼면 해당 테스트 실패 ✓ · 스크린샷 확인 · 커밋 `T31-2: 그리는 동안 길이 표시`
- [x] T31-3 터치로 끌 때 손가락 위 돋보기 보여주기
  - 완료: 손가락으로 그리기 도구를 끄는 동안 손가락 위쪽에 둥근 돋보기가 뜨고, 손가락 아래 영역을 확대해 벽·미리보기 선·붙을 곳 표시(고리·점)를 보여준다. 찍히는 좌표는 손가락 자리 그대로다. 손가락을 떼면 사라진다. 실제 테스트 — 모바일 CDP 터치로 끄는 동안 돋보기가 보이고 떼면 사라짐, 찍힌 좌표가 손가락 자리와 같음. 엣지 — 마우스로는 돋보기가 뜨지 않음, 화면 위쪽 가장자리에서는 돋보기가 화면 안으로 옮겨짐, 선택 도구로 끌 때는 뜨지 않음 · 의존 T31-2
  - 결과: 코드 160개 통과(돋보기 자리 6개 새로) · 실제 212개 통과(40개 건너뜀: 터치는 모바일 크롬만) · 엣지: 마우스·선택 도구는 안 뜸, 2D 평면도 위 가장자리에서는 손가락 옆으로 비켜 영역 안, 두 번째 손가락이 닿으면 사라짐, 사각형도 뜸 · 돋보기 가운데 = 붙을 점, 2배 크기 · 터치 조건을 빼면 마우스 테스트, 위 공간 확인을 빼면 가장자리 테스트 실패 ✓ · 돋보기 안에도 같은 그림이 있어 기존 실제 테스트는 2D 평면도 안만 보게 바꿈 · 스크린샷 확인 · 커밋 `T31-3: 터치로 끌 때 손가락 위 돋보기`
