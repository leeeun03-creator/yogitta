# T16. 물건을 옮기고, 칸 수 감소·가구 삭제 때 물건 지키기

챕터 5. 물건과 저장 · P0 · 의존 T8 · PRD F7, F13 / US6 · 인수 조건 "칸 수 감소", "가구 삭제"
완료 기준: 물건을 다른 칸·가구로 옮길 수 있다. 칸 수를 줄이면 사라진 칸의 물건이 "칸 없음"으로 가고 알림이 뜬다. 물건 든 가구를 지우면 "같이 지우기 / 다른 가구로 옮기기"를 묻는다

- [x] 가구 상세 패널에서 물건 칩을 누르고 [고치기]를 누르면 이름·칸·메모가 채워져 열리고, 고쳐 [저장]하면 바뀐다. 칸을 바꾸면 그 칸 행으로 옮겨진다
- [x] 고치기에서 빈 이름·31자 이름은 막히고 까닭이 뜬다. Esc·[취소]는 고치기만 닫는다 ← 엣지
- [x] 가구가 둘 이상이면 고치기에 [가구]가 있어, 다른 가구를 고르면 칸이 그 가구의 칸으로 바뀌고(칸 없음부터) 저장하면 "여권을 보관함 1에 옮겼어요"가 뜬다. 목록의 물건 수가 따라 바뀐다
- [x] 편집 모드에서 서랍 4칸 중 4번째 서랍에 물건이 있을 때 칸을 3으로 줄이면 속성 패널에 "물건 N개를 칸 없음으로 옮겼어요"가 뜨고, 가구 상세 패널의 칸 없음 행에 들어가 있다. 비어 있는 칸을 줄일 때는 알림이 없다 ← 엣지
- [x] (휴대폰) 칸을 줄였을 때 알림이 속성 패널 안에서 보이게 올라온다 ← 엣지
- [x] 물건이 든 가구를 [삭제]·Delete 키·지우개로 지우면 "보관함 1을 지울까요?"가 뜬다. [같이 지우기]는 물건까지 지우고, [옮기고 지우기]는 고른 가구의 칸 없음으로 옮긴 뒤 지운다
- [x] 위 삭제는 되돌리기 한 번에 가구와 물건이 함께 돌아온다. 빈 가구는 묻지 않고 바로 지워진다 ← 엣지
- [x] 다른 가구가 없으면 삭제 확인에 옮기기가 없다. Esc·[취소]는 지우지 않는다 ← 엣지

## 메모

- 물건은 좌표가 아니라 가구에 속하므로(PRD 부록 B) 가구를 옮기거나 돌려도 물건은 그대로다
- 다른 공간의 가구로 옮기기는 하지 않는다 (현재 공간 안에서만)
- useEffect를 `() => el.scrollIntoView()`처럼 식으로 쓰면 최신 크롬에서 돌려주는 값을 React가 정리 함수로 불러 화면이 멈춘다. 블록(`{ ...; }`)으로 쓴다 (T16-3 작업 중)
