# T28. 검색 결과를 3D에서 위치 표시하기

## 세부 Todo

- [ ] T28-1 찾은 가구는 주황, 나머지 가구는 흐리게 칠하기
  - 완료: 검색으로 고른 결과(T10-2)의 가구는 찾은 가구 색(#E5893A, 면 음영 그대로)이고, 나머지 가구는 바탕색 쪽으로 55% 섞어 흐리게 칠한다(yogitta-design 5장). 3D 그림 이름에 "찾은 가구 화장대 서랍장"이 붙는다. 결과를 바꾸면 따라가고 검색어를 지우면 원래 색. 코드 테스트 — 색 섞기(0%·55%·100%, 형식). 실제 테스트 — 여권 검색 시 3D 이름·라벨 표시, 결과 바꾸기, 지우기. 엣지 — 고른 가구 표시(T9)와 함께, 다른 공간 결과만 있을 때는 강조 없음 · 의존 T10-2
- [ ] T28-2 찾은 칸 열기
  - 완료: 찾은 칸이 열린다(짧은 애니메이션, 동작 줄이기 설정이면 바로): 서랍장은 그 서랍이 정면으로 26cm 빠져나오고 열린 칸 색(#FFB877, 안쪽 #7A3D10), 선반·벽걸이는 그 칸이 열린 칸 색으로 앞으로 나오고, 양문 수납장은 그쪽 문이 열려 그 칸이 열린 칸 색으로 보인다. 책상·테이블·침대·보관함과 칸 없음 물건은 열지 않고 가구 전체만 강조한다. 3D 그림 이름에 "2번째 서랍 열림". 코드 테스트 — 열릴 부품 고르기(가구 8종·칸 없음). 실제 테스트 — 여권(서랍), 겨울 코트(양문 수납장), 보조배터리(책상, 열림 없음). 엣지 — 결과를 바꾸면 앞 칸은 닫히고 새 칸이 열림, 검색어를 지우면 닫힘 · 의존 T28-1
- [ ] T28-3 바닥 점선 원과 칸 위 핀 띄우기
  - 완료: 찾은 가구 바닥에 강조색 점선 원 2개(안쪽 진하게, 바깥 반투명)를 깔고, 칸 위로 강조색 선과 둥근 라벨 "여권 / 화장대 서랍장 · 2번째 서랍" 핀을 띄운다. 지금 공간에서 여러 곳 찾으면 결과마다 핀(고른 결과만 칸이 열린다). 실제 테스트 — 핀 라벨 글자, 여러 곳이면 핀 여러 개, 결과를 고르면 그 핀이 앞. 엣지 — 칸 없음은 가구 위에 핀, 핀 라벨이 3D 보기 버튼을 가리지 않음, 휴대폰 화면 · 의존 T28-2
