- [ ] "보조배터리"(책상)·"크리스마스"(보관함, 칸 없음)는 칸을 열지 않고 가구만 주황 + 핀이다 ← 엣지

- [ ] 검색어를 지우면 색·칸·핀이 원래대로 돌아간다 ← 엣지
- [ ] (사용자, 눈으로) 칸이 열리는 움직임과 핀·점선 원 크기가 알맞다
