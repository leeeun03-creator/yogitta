# T5. 구역 목록 관리하기 (추가·이름 변경·삭제)

챕터 3. 공간 · P0 · 의존 T2 · PRD F6
완료 기준: 편집 모드 하단에서 구역을 추가·이름 변경·삭제할 수 있고, 같은 이름은 막힌다
변경 로그: [log/T5.md](log/T5.md)

## 세부 Todo

- [ ] T5-1 구역 이름 검사와 store 액션 만들기
  - 완료: 현재 공간에 구역을 더하고(`addRoom`), 이름을 바꾸고(`renameRoom`, 그 구역의 가구도 같이), 지우는(`removeRoom`, 그 구역의 가구는 구역 없음) 순수 함수와 store 액션이 있다. 모두 되돌리기 기록에 남는다. 코드 테스트 — 추가·이름 변경·삭제, 가구 구역이 따라 바뀜. 엣지 — 빈 이름·공백만, 앞뒤 공백은 지움, 같은 이름(띄어쓰기·대소문자만 다른 것도 같은 이름), 자기 이름 그대로 바꾸기는 그대로, 10자 넘음, 없는 구역 바꾸기·지우기는 그대로, 원본을 바꾸지 않음 · 의존 T13-1
  - 실제 테스트는 구역 목록이 생기는 T5-2에서 함께 한다 (`yogitta-test` 2장 예외)
- [ ] T5-2 하단에 구역 목록 보이고 구역 추가하기 (시안 04)
  - 완료: 2D 평면도 아래 줄 왼쪽에 "구역" 라벨, 구역 칩, 점선 "+ 구역 추가" 칩이 있다. 누르면 이름 입력칸이 나오고 Enter(또는 확인)로 더하고, Esc로 취소한다. 같은 이름·빈 이름은 막히고 안내 문구가 나온다. 실제 테스트 — 추가하면 칩이 생김, 되돌리기로 사라짐, 입력 중 Ctrl+Z는 글자만. 엣지 — 빈 이름·같은 이름 안내, 10자 넘게 못 씀, 구역 0개, 구역 많음(줄바꿈, 360px 가로 스크롤 없음), 터치 영역 44px, 키보드만으로 추가 · 의존 T5-1
- [ ] T5-3 구역 이름 바꾸기·삭제하기
  - 완료: 구역 칩을 누르면 그 칩이 선택(강조색)되고 이름 입력칸과 삭제 버튼이 나온다. 이름을 바꾸면 칩이 바뀌고, 삭제하면 칩이 사라진다(가구는 구역 없음, 되돌리기로 돌아옴). 실제 테스트 — 이름 바꾸기, 삭제, 되돌리기. 엣지 — 다른 구역과 같은 이름은 막힘, 이름을 그대로 두고 확인, Esc로 취소하면 그대로, 키보드만으로 바꾸기·삭제, 스크린샷을 시안 04와 비교 · 의존 T5-2
