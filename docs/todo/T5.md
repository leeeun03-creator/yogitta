- [ ] 칩을 누르면 강조색이 되고, 이름을 바꾸고 Enter를 누르면 칩 이름이 바뀐다

- [ ] 이름을 쓰는 중에 Ctrl+Z를 누르면 글자만 지워지고 구역은 그대로다 ← 엣지
- [ ] Esc를 누르거나 고른 칩을 다시 누르면 바뀌지 않고 닫힌다 ← 엣지
- [ ] 휴대폰에서 구역을 여러 개 더해도 줄바꿈되고 화면 밖으로 나가지 않는다 ← 엣지
