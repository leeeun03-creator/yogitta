# 요깃따 직접 확인 체크리스트

`yogitta-test` 스킬의 6장이다 (장 번호는 그대로 둔다). 목차와 늘 지킬 것은 `yogitta-test`에 있다.

## 6. 큰 Todo 끝 — 직접 확인 체크리스트

큰 Todo(Tn)의 마지막 세부 Todo가 끝나면, 사용자에게 아래 형식으로 체크리스트를 준다. 사용자가 확인해야 큰 Todo를 완료로 본다.

```
T2 직접 확인 (배포 주소: https://leeeun03-creator.github.io/yogitta/)
- [ ] 처음 열면 첫 실행 화면이 보인다
- [ ] 빠른 선택 "투룸"을 누르면 9.0 × 6.0이 들어간다
- [ ] 가로에 0을 넣으면 버튼이 막히고 안내 문구가 나온다   ← 엣지
- [ ] 휴대폰으로 열어도 카드가 화면 밖으로 나가지 않는다     ← 엣지
```

- 자동 테스트로 확인하기 어려운 것(느낌, 애니메이션, 3D 모양, 실제 휴대폰)을 중심으로 5~10개
- 문제가 나오면 `Tn-n 버그수정[영역]` 커밋으로 고친다 (다시 깨질 만하면 테스트 하나를 더한다)
