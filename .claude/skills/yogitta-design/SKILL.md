# 요깃따 디자인 규칙 (B안 · 미니어처 하우스)

요깃따의 모든 화면은 이 문서를 따른다. 우드톤 디오라마 같은 3D, 완전히 둥근 버튼, 부드러운 그림자로 **아늑한 미니어처 집** 느낌을 낸다.
원본 시안: `docs/design/README.md` (화면 이미지 01~05, 원본 HTML `docs/design/boards/`). 화면을 만들 때 해당 이미지를 열어 모양을 맞춘다.

## 0. 작업 전 체크

1. 새 색을 만들지 말고 아래 토큰만 쓴다 (`var(--yg-…)`)
2. 글꼴은 제목 Jua, 본문 Gowun Dodum 두 개뿐
3. 버튼·검색창·칩은 알약형, 카드·패널은 둥근 모서리 + 부드러운 그림자
4. 3D에서 강조색은 "찾은 가구" 하나에만 쓴다
5. 끝나면 "11. 하지 말 것"을 다시 확인한다

## 1. 색 토큰

`src/styles/tokens.css`에 그대로 넣는다.

```css
:root {
  /* 바탕 */
  --yg-bg: #F4ECDF;          /* 전체 배경 */
  --yg-surface: #FFFAF3;     /* 카드, 패널, 검색창, 입력칸 */
  --yg-surface-2: #F8EFE3;   /* 칸 목록 행, 입력 필드 배경 */
  --yg-canvas: #FBF6EE;      /* 3D·2D 캔버스 영역 */
  --yg-chip: #F3E6D4;        /* 일반 칩, 세그먼트 바탕 */

  /* 글자 */
  --yg-text: #3B2F25;        /* 본문 */
  --yg-text-sub: #7A6450;    /* 라벨, 설명 (대비 5:1 이상) */

  /* 강조 */
  --yg-accent: #A8501B;      /* 주 버튼, 검색창 테두리, 찾은 물건 칩, 핀, "요깃따!" */
  --yg-accent-hover: #7C3A12;
  --yg-on-accent: #FFF8EF;   /* 강조색 위 글자 */
  --yg-found-bg: #F6D9BF;    /* 찾은 물건이 든 칸 배경 */
  --yg-found-text: #6B2F0C;  /* 찾은 칸 안 라벨 */

  /* 선 */
  --yg-border: #E6D6BF;
  --yg-border-soft: #EADCC7;
  --yg-dashed: #D9B48F;      /* "+ 추가" 점선 버튼 */

  /* 상태 */
  --yg-danger: #9B2C1F;      /* 삭제 글자 */
  --yg-danger-border: #E3B9AE;

  /* 모양 */
  --yg-radius-pill: 999px;
  --yg-radius-card: 20px;
  --yg-radius-panel: 24px;
  --yg-radius-canvas: 28px;
  --yg-radius-row: 16px;
  --yg-radius-field: 14px;
  --yg-shadow-card: 0 8px 24px rgba(120, 80, 40, 0.14);
  --yg-shadow-panel: 0 10px 30px rgba(120, 80, 40, 0.12);
  --yg-shadow-pop: 0 18px 44px rgba(90, 60, 30, 0.24);
}
```

## 2. 글꼴

```html
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Gowun+Dodum&family=Jua&display=swap">
```

| 용도 | 글꼴 | 크기 |
|---|---|---|
| 로고, 화면 제목, 가구 이름(패널 제목), "요깃따!" | Jua | 22–32px |
| 본문, 버튼, 입력, 칩 | Gowun Dodum | 14–18px |
| 라벨, 보조 설명 | Gowun Dodum | 13px, `--yg-text-sub` |

- 최소 글자 크기 12px
- Jua는 굵기가 하나라 `font-weight`를 주지 않는다

## 3. 아이콘

- 선 아이콘(lucide-react), 굵기 2, 크기 16–22px
- 이모지 금지
- 아이콘만 있는 버튼은 반드시 `aria-label`

## 4. 컴포넌트

### 버튼
| 종류 | 모양 |
|---|---|
| 주 버튼 | `--yg-accent` 바탕, `--yg-on-accent` 글자, 알약형, 높이 48px |
| 보조 버튼 | `--yg-surface` 바탕, 1px `--yg-border`, 알약형, 높이 44px |
| 아이콘 버튼 | 44×44 원형, 보조 버튼과 같은 색 |
| 추가 버튼 | 투명 바탕, 2px 점선 `--yg-dashed`, 글자 `--yg-accent`, 내용 "+ 새 공간 만들기" 등 |
| 삭제 버튼 | 투명 바탕, 1px `--yg-danger-border`, 글자 `--yg-danger` |

### 검색창
- 알약형, 높이 56–60px, 최대 폭 640px, 가운데 정렬
- 2px `--yg-accent` 테두리 + `--yg-shadow-card`
- 왼쪽 돋보기 아이콘(강조색), placeholder "무엇을 찾고 있나요?"
- 화면에 안 보이는 `<label>`("물건 검색")을 반드시 연결

### 칩 (물건 이름)
- 알약형, 패딩 5px 12px, 15px
- 기본: `--yg-surface` (칸 행 안) 또는 `--yg-chip` (카드 안)
- 찾은 물건: `--yg-accent` 바탕 + `--yg-on-accent` 글자

### 검색 결과 카드
순서를 바꾸지 않는다.
1. **"요깃따!"** — Jua 30px, `--yg-accent` + 옆에 "'여권' 1곳 찾음" (13px, sub)
2. 위치 문장 — 17px, 줄간격 1.65. 물건·공간은 굵게, 가구 이름은 굵게 + 강조색
3. 메모 — 메모 아이콘 + 14px sub
4. 같은 칸 물건 — "같은 칸에 있는 물건" 라벨 + 칩 (최대 4개 + "외 n개")
5. 다른 공간 링크 — "다른 공간에도 있어요: 형 방 1곳 ›" (강조색 링크)

카드: `--yg-surface`, `--yg-radius-card`, `--yg-shadow-card`, 패딩 18px 20px, 최대 폭 460px

### 가구 상세 패널
- `--yg-surface`, `--yg-radius-panel`, `--yg-shadow-panel`, 패딩 22px, 폭 320–400px
- 머리: 48px 아이콘 타일(`--yg-found-bg` 바탕, 강조색 아이콘) + 가구 이름(Jua 24) + 위치 핀 아이콘 + "내 방 · 침대 옆 · 물건 5개"(14px sub) + 닫기 버튼
- 칸 행: `--yg-surface-2`, `--yg-radius-row`, 패딩 12px 14px, 왼쪽 칸 이름(13px sub, 폭 40px) + 칩
- 찾은 칸 행: `--yg-found-bg` 바탕, 칸 이름 `--yg-found-text`
- 빈 칸: "비어 있어요" (14px sub)
- 맨 아래 주 버튼 "물건 넣기"

### 공간 전환 드롭다운
- 버튼: 알약형, 2px 강조 테두리, "공간" 라벨(13px sub) + 공간 이름 + 화살표
- 목록: `--yg-surface`, 22px 모서리, `--yg-shadow-pop`, 폭 340px
- 항목: 76×56 미니 3D 썸네일 + 이름(16) + "6.0 × 4.5 m · 가구 6 · 물건 23"(13 sub), 선택된 항목은 `--yg-found-bg` 바탕 + 체크 아이콘
- 맨 아래 점선 추가 버튼 "+ 새 공간 만들기"

### 편집 모드
- 상단 바: 주 버튼 "‹ 완료", 제목 "편집 모드"(Jua 22), "자동 저장됨"(13 sub), 세그먼트 [2D 평면도 | 3D 미리보기], 되돌리기·다시하기 아이콘 버튼
- 왼쪽 그리기 도구 막대: `--yg-surface`, 22px 모서리, 버튼 64×60(아이콘 + 12px 라벨). 선택된 도구는 강조색 바탕
  - 순서: 선택, 직선, 연속선, 사각형, 가구, 지우개
- 오른쪽 속성 패널: 가구 이름 입력 → 종류(4열 그리드 8개) → 놓인 곳 세그먼트(바닥 / 가구 위 / 벽에 걸기) → 크기(가로·깊이·높이 cm) → 칸 수 스테퍼 + 칸별 높이 입력 + 왼쪽 칸 비율 미리보기 + "합계 90 / 전체 높이 90" → 회전·삭제 버튼 → 안내 문구
- 하단: "구역" 칩 목록 + "+ 구역 추가" 점선 칩, 격자 스냅 토글, "바닥 6.0 × 4.5 m" 버튼

### 세그먼트 컨트롤
- `--yg-chip` 바탕의 알약 안에 버튼들, 선택된 것만 `--yg-surface` + 작은 그림자

### 입력칸
- `--yg-surface-2` 바탕, 1px `--yg-border`, `--yg-radius-field`, 높이 44–48px
- 강조할 칸(예: 찾은 칸의 높이)은 2px 강조 테두리 + `--yg-surface`

## 5. 3D 장면

### 색
| 대상 | 색 |
|---|---|
| 바닥 (마루) | `#DCBB91`, 50cm 격자선 `#CFA87A` |
| 벽 | `#F6EAD8` |
| 가구 (나무 톤) | 책상·테이블 `#B98A5E`, 선반·양문 수납장·벽걸이 `#A6754D`, 침대 `#C99A6C`, 매트리스 `#F7EFE3`, 보관함 `#CDB79C` |
| 찾은 가구 | `#E5893A` |
| 열린 칸 | `#FFB877`, 안쪽 `#7A3D10` |
| 모서리 선 | `#9B7A5A` |

- 면 음영: 윗면 = 기본색, 앞면 = 86%, 옆면 = 74% 밝기 (조명으로 내도 비슷하게 맞춘다)
- 텍스처·반사·그림자 맵 없음. 단색 재질(`meshStandardMaterial` 또는 `meshLambertMaterial`)
- 벽 높이는 실제(240cm)보다 낮게 110cm로 잘라 보여준다 (컷어웨이). 카메라 쪽 벽은 반투명 가능
- 기본 카메라: 등각에 가까운 대각선 위에서 내려다보기

### 위치 표시 (검색 후, 반드시 이 순서로)
1. 찾은 가구만 `#E5893A`, 나머지 가구는 바탕색 쪽으로 55% 섞어 흐리게
2. 칸 열림: 물건이 든 칸이 정면으로 26cm 정도 빠져나온다 (짧은 애니메이션)
3. 가구 바닥에 강조색 점선 원 2개 (안쪽 진하게, 바깥 반투명)
4. 칸 위로 핀: 강조색 선 + 둥근 라벨 "여권 / 화장대 서랍장 · 2번째 서랍"
5. 카메라가 그 칸 정면이 보이도록 부드럽게 이동
- 칸 지정 없는 물건 → 가구 전체만 강조, 칸 열림은 하지 않는다
- 같은 이름이 여러 곳 → 핀 여러 개

### 가구 클릭
- 호버: 살짝 밝게 + 이름 라벨
- 클릭: 회전 드래그와 구분(이동 거리 작을 때만), 벽은 클릭 판정에서 제외

## 6. 2D 평면도 (편집 모드)

- 2D 평면도 바탕: `--yg-surface`, 50cm 격자선 `#F0E3D0`, 바닥 테두리 `#D9C3A5`
- 벽: `#6E5236`, 두께 12, 끝 square. 연결점은 흰 원 + 갈색 테두리
- 가구: 나무 톤의 연한 색 사각형 + 같은 계열 테두리 1.5, 6px 모서리, 가운데 이름(14)
- 정면 방향: 앞쪽 가장자리에 작은 삼각형
- 보관함(처음 놓은 상태): 점선 테두리
- 선택: 강조색 테두리 2.5 + 모서리 핸들 4개(흰 사각형) + 위쪽 회전 핸들 + 이름 알약 라벨
- 치수: 위쪽 "6.0 m", 왼쪽 세로 "4.5 m" (14px sub)

## 7. 레이아웃

| 화면 | 구조 |
|---|---|
| 메인 화면 | 헤더(로고 · 공간 버튼 · 편집 버튼) → 가운데 검색창 → [3D 공간 (넓게) + 가구 상세 패널 (320–400px)] |
| 편집 모드 | 상단 바 → [그리기 도구 막대 + 2D 평면도 + 속성 패널] |
| 첫 실행 화면 | 가운데 큰 점선 `+` 카드 + 바닥 크기 카드 (원룸 / 투룸 / 아파트 빠른 선택) |
| 모바일 (≤ 640px) | 헤더(로고 · 공간 버튼 · 편집 아이콘) → 검색창 → 3D → 하단 시트(결과·칸) |

- 바깥 여백 32px(모바일 16px), 영역 사이 24px
- 3D 공간·2D 평면도 영역: `--yg-canvas` + `--yg-radius-canvas` + 안쪽 1px `--yg-border-soft`
- 넓은 화면에서 패널은 오른쪽, 좁아지면 아래로 내려간다 (flex-wrap)

## 8. 문구 톤

- 반말 아닌 부드러운 존댓말 "~해요"
- 찾음: **"요깃따!"** → "여권은 내 방의 화장대 서랍장 위에서 2번째 서랍에 보관 중이에요."
- 못 찾음: "아직 어딨는지 몰라요. '여권' 지금 등록할까요?"
- 빈 칸: "비어 있어요" / 공간 없음: "아직 공간이 없어요"
- 은/는은 마지막 글자 받침으로 자동 선택

## 9. 접근성

- 터치 영역 44px 이상
- 본문 대비 4.5:1 이상 (`--yg-text-sub`까지 통과)
- 실제 `<button>`, `<input>` + `<label>` 사용, div에 onClick 금지
- 강조는 색만으로 구분하지 않는다 (찾은 칸은 배경 + 굵은 칩 + 핀으로 함께 표시)

## 10. 파일 위치

폴더 구조는 `yogitta-code` 1장을 따른다.

```
src/styles/tokens.css                   ← 1장 토큰
src/shared/ui/                          ← Button, Chip, SearchBar, Segmented, Panel
src/features/search/components/         ← ResultCard ("요깃따!")
src/shared/constants/colors3d.ts        ← 5장 3D 색 (상수로)
```

## 11. 하지 말 것

- 토큰에 없는 색, 그라데이션 배경, 네온·보라 계열
- 각진 버튼(4px 이하 모서리), 진한 그림자
- 3D에 텍스처·사실적인 재질·여러 강조색
- 이모지 아이콘
- "요깃따!"를 찾지 못한 상황이나 다른 곳에 쓰는 것 (찾았을 때만)
