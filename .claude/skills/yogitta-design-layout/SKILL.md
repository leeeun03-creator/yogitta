# 요깃따 레이아웃·문구·접근성

`yogitta-design` 스킬의 7~10장이다 (장 번호는 그대로 둔다). 목차와 늘 지킬 것은 `yogitta-design`에 있다.

## 7. 레이아웃

| 화면 | 구조 |
|---|---|
| 메인 화면 | 헤더(로고 · 공간 버튼 · 편집 버튼) → 가운데 검색창 → [3D 공간 (넓게) + 가구 상세 패널 (320–400px)] |
| 편집 모드 | 상단 바 → [그리기 도구 막대 + 2D 평면도 + 속성 패널] |
| 첫 실행 화면 | 가운데 큰 점선 `+` 카드 + 바닥 크기 카드 (원룸 / 투룸 / 아파트 빠른 선택) |
| 모바일 (≤ 640px) | 헤더(로고 · 공간 버튼 · 편집 아이콘) → 검색창 → 3D → 하단 시트(결과·칸) |

- 바깥 여백 32px(모바일 16px), 영역 사이 24px
- 3D 공간·2D 평면도 영역: `--yg-canvas` + `--yg-radius-canvas` + 안쪽 1px `--yg-border-soft`
- 넓은 화면에서 패널은 오른쪽, 좁아지면 아래로 내려간다 (flex-wrap)

## 8. 문구 톤

- 반말 아닌 부드러운 존댓말 "~해요"
- 찾음: **"요깃따!"** → "여권은 내 방의 화장대 서랍장 위에서 2번째 서랍에 보관 중이에요."
- 못 찾음: "아직 어딨는지 몰라요. '여권' 지금 등록할까요?"
- 빈 칸: "비어 있어요" / 공간 없음: "아직 공간이 없어요"
- 은/는은 마지막 글자 받침으로 자동 선택

## 9. 접근성

- 터치 영역 44px 이상
- 본문 대비 4.5:1 이상 (`--yg-text-sub`까지 통과)
- 실제 `<button>`, `<input>` + `<label>` 사용, div에 onClick 금지
- 강조는 색만으로 구분하지 않는다 (찾은 칸은 배경 + 굵은 칩 + 핀으로 함께 표시)

## 10. 파일 위치

폴더 구조는 `yogitta-code` 1장을 따른다.

```
src/styles/tokens.css                   ← 1장 토큰
src/shared/ui/                          ← Button, Chip, SearchBar, Segmented, Panel
src/features/search/components/         ← ResultCard ("요깃따!")
src/shared/constants/colors3d.ts        ← 5장 3D 색 (상수로)
```
