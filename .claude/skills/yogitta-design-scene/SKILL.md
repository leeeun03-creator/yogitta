# 요깃따 3D 장면과 2D 평면도

`yogitta-design` 스킬의 5~6장이다 (장 번호는 그대로 둔다). 목차와 늘 지킬 것은 `yogitta-design`에 있다.

## 5. 3D 장면

### 색
| 대상 | 색 |
|---|---|
| 바닥 (마루) | `#DCBB91`, 50cm 격자선 `#CFA87A` |
| 벽 | `#F6EAD8` |
| 가구 (나무 톤) | 책상·테이블 `#B98A5E`, 선반·양문 수납장·벽걸이 `#A6754D`, 침대 `#C99A6C`, 매트리스 `#F7EFE3`, 보관함 `#CDB79C` |
| 찾은 가구 | `#E5893A` |
| 열린 칸 | `#FFB877`, 안쪽 `#7A3D10` |
| 모서리 선 | `#9B7A5A` |

- 면 음영: 윗면 = 기본색, 앞면 = 86%, 옆면 = 74% 밝기 (조명으로 내도 비슷하게 맞춘다)
- 텍스처·반사·그림자 맵 없음. 단색 재질(`meshStandardMaterial` 또는 `meshLambertMaterial`)
- 벽 높이는 실제(240cm)보다 낮게 110cm로 잘라 보여준다 (컷어웨이). 카메라 쪽 벽은 반투명 가능
- 기본 카메라: 등각에 가까운 대각선 위에서 내려다보기

### 위치 표시 (검색 후, 반드시 이 순서로)
1. 찾은 가구만 `#E5893A`, 나머지 가구는 바탕색 쪽으로 55% 섞어 흐리게
2. 칸 열림: 물건이 든 칸이 정면으로 26cm 정도 빠져나온다 (짧은 애니메이션)
3. 가구 바닥에 강조색 점선 원 2개 (안쪽 진하게, 바깥 반투명)
4. 칸 위로 핀: 강조색 선 + 둥근 라벨 "여권 / 화장대 서랍장 · 2번째 서랍"
5. 카메라가 그 칸 정면이 보이도록 부드럽게 이동
- 칸 지정 없는 물건 → 가구 전체만 강조, 칸 열림은 하지 않는다
- 같은 이름이 여러 곳 → 핀 여러 개

### 가구 클릭
- 호버: 살짝 밝게 + 이름 라벨
- 클릭: 회전 드래그와 구분(이동 거리 작을 때만), 벽은 클릭 판정에서 제외

## 6. 2D 평면도 (편집 모드)

- 2D 평면도 바탕: `--yg-surface`, 50cm 격자선 `#F0E3D0`, 바닥 테두리 `#D9C3A5`
- 벽: `#6E5236`, 두께 12, 끝 square. 연결점은 흰 원 + 갈색 테두리
- 가구: 나무 톤의 연한 색 사각형 + 같은 계열 테두리 1.5, 6px 모서리, 가운데 이름(14)
- 정면 방향: 앞쪽 가장자리에 작은 삼각형
- 보관함(처음 놓은 상태): 점선 테두리
- 선택: 강조색 테두리 2.5 + 모서리 핸들 4개(흰 사각형) + 위쪽 회전 핸들 + 이름 알약 라벨
- 치수: 위쪽 "6.0 m", 왼쪽 세로 "4.5 m" (14px sub)
- 구역 선: 벽 색 `#6E5236`, 화면 2px 점선 (6px 간격). 3D에는 서지 않는다. 두 끝에는 벽 연결점과 같은 흰 원(벽·바닥 테두리에 닿은 표시)
- 구역: 구획을 파스텔 색으로 칠하고(불투명도 0.7), 구역 기준점 자리에 이름(14px, `--yg-text`). 색은 구역 목록 순서대로 아래 6색을 돌려 쓴다 (7번째부터 처음 색). 고른 구역은 불투명도 1로 진하게 + 이름을 강조색으로
  - 복숭아 `#F9D5C2` → 민트 `#CDEBD9` → 하늘 `#CFE3F3` → 버터 `#F7E7B4` → 장미 `#F5CFD6` → 세이지 `#DCE5C8`
  - 3D 미리보기 바닥에도 같은 색을 옅게 칠한다
- 누르면 새 구역이 될 이름 없는 구획(마우스를 올림, 이름 입력칸이 뜬 동안): 새 구역이 받을 색으로 불투명도 0.35
